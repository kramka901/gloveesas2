# Telegram Бот обратной связи (Support / Feedback Bot)

Бот позволяет пользователям писать любые сообщения (текст, фото, голосовые, документы), пересылает их вам (администратору), и позволяет отвечать конкретному пользователю прямо через Telegram.

---

## 🚀 Быстрый старт за 3 шага

### Шаг 1. Получите токен бота
1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте ему команду `/newbot`.
3. Придумайте имя для бота и юзернейм (должен заканчиваться на `bot`, например `MyFeedback_bot`).
4. Скопируйте выданный токен (вида `1234567890:ABCdef...`).

### Шаг 2. Узнайте свой Telegram ID
1. Напишите боту **[@userinfobot](https://t.me/userinfobot)** в Telegram.
2. Он пришлет ваш числовой `Id` (например, `987654321`).

### Шаг 3. Заполните файл `.env`
Откройте файл `.env` в папке проекта `C:\Users\Honor\PycharmProjects\PythonProject3\.env` и вставьте ваши значения:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_IDS=987654321
```

## 💡 Как работает бот

1. **Пользователь пишет боту:**
   - Пользователь отправляет боту `/start`, а затем любой вопрос, фото, голосовое сообщение, кружочек или файл.
   - Бот подтверждает пользователю: *«Ваше сообщение принято! Администратор ответит вам в ближайшее время»*.

2. **Администратор получает уведомление:**
   - Администратору приходит карточка с данными отправителя (Имя, @username, User ID).
   - Следом приходит точная копия сообщения пользователя.

3. **Ответ пользователю:**
   - Администратор просто свайпает / нажимает **«Ответить» (Reply)** на карточку или на полученное сообщение, вводит текст (или прикрепляет фото/файл) и нажимает отправить.
   - Бот автоматически находит нужного пользователя в базе данных и отправляет ему ответ с пометкой *«Ответ от администратора»* и ссылкой на исходный вопрос!

## 🛠 Команды администратора

- `Reply` (свайп сообщения) — ответ на сообщение пользователя.
- `/reply <ID> <текст>` — отправка сообщения пользователю напрямую по его ID (например: `/reply 123456789 Здравствуйте, ваш вопрос решен`).
- `/stats` — статистика (количество пользователей, число входящих и исходящих сообщений, число заблокированных).
- `/block <ID>` — заблокировать спамера.
- `/unblock <ID>` — разблокировать пользователя.
- `/id` — узнать свой Telegram ID.
- `/help` — справка по командам.

## 🗄 База данных
Бот сохраняет связи сообщений и список пользователей в локальную базу данных SQLite (`bot_database.sqlite`). Даже если бот перезагрузится, вы сможете ответить на сообщения, отправленные ранее.
